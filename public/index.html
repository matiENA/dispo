🔗 ¿Quieres un Botón dentro de tu Google Sheet?

Puedes agregar este snippet en Google Sheets (menú Extensiones > Apps Script) para ejecutar la carga directamente con un clic dentro de la planilla:

function cargarRuteoDelDia() { const url = "https://dispo-yp8n.onrender.com/api/ruteo/procesar-hoy"; const options = { method: "post", contentType: "application/json" }; const response = UrlFetchApp.fetch(url, options); SpreadsheetApp.getUi().alert("✔ Ruteo cargado: " + response.getContentText()); }
