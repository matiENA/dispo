Extracción de Planilla de Google Drive, Inyección en Sheet y Transmisión de Cards

🚀 Cargar y Transmitir Cards
📊 Estado de Ejecución LISTO
Selecciona una fecha arriba y haz clic en "Cargar Planilla y Enviar Cards" para iniciar.
🔗 Menú / Botón dentro de tu Google Sheet (Apps Script)

Puedes pegar este script en tu planilla en Extensiones > Apps Script. Creará un menú 🚛 Ruteo Logística > 🚀 Cargar y Enviar Cards directamente en Google Sheets:

// Agrega un menú dentro de Google Sheets automáticamente function onOpen() { const ui = SpreadsheetApp.getUi(); ui.createMenu('🚛 Ruteo Logística') .addItem('🚀 Cargar Planilla y Enviar Cards a Choferes', 'ejecutarEnvioCards') .addToUi(); } function ejecutarEnvioCards() { const url = "https://dispo-yp8n.onrender.com/api/ruteo/trigger/enviar-cards"; const options = { method: "post", contentType: "application/json", payload: JSON.stringify({ fecha: "today" }), muteHttpExceptions: true }; const response = UrlFetchApp.fetch(url, options); SpreadsheetApp.getUi().alert("🚀 Paquete diario de Cards enviado a Choferes:\n\n" + response.getContentText()); }
